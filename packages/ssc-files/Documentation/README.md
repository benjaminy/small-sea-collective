# Small Sea Collective Files

Decentralized file sharing!

Small Sea Files works similarly to conventional cloud file sharing (Dropbox, Nextcloud Files, etc).
But it's a Small Sea app, which means that there is no Small Sea Files service running on the internet somewhere for all Small Sea Files users.
Rather every Files niche (a shared folder) belongs to some Small Sea Team, and changes made locally are published to teammates according to each user's own services and Small Sea setup.
